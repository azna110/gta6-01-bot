Velvet Bay — an original 3D open-world crime game built for make.fun's "Make GTA 6" bounty. Explore a sun-soaked coastal city on foot and by car, steal cars, outrun the police, and work off a $2,000 debt across four story missions. Built with Three.js; no build step, no network.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome. Or open `game/index.html` directly — the whole game is static files under `game/`.

## How to play

- **WASD** — move on foot / drive
- **Mouse** — orbit camera (click to lock the pointer)
- **Shift** — sprint
- **Space** — jump on foot / handbrake in a car
- **E** — steal / enter / exit a car
- **Click** — shoot (12-round pistol, **R** reloads), **F** — punch
- **P** — pause

Steal cars, raise your wanted level, lose the police, and finish all four jobs for Dante Reyes to clear Lena's debt. Progress saves automatically in your browser.
